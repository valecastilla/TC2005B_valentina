Eventos y DOM

1. ¿Qué es el DOM?

El DOM (Document Object Model) es una representación en memoria de un documento HTML como un árbol de objetos. Proporciona una interfaz de programación que permite que los scripts (generalmente JavaScript) accedan y manipulen el contenido, la estructura y el estilo de un documento web.

El DOM representa cada elemento HTML como un nodo en una estructura de árbol, permitiendo a los desarrolladores utilizar métodos y propiedades para acceder, modificar, añadir o eliminar elementos del documento.

Referencia: https://www.freecodecamp.org/espanol/news/que-es-el-dom-el-significado-del-modelo-de-objeto-de-documento-en-javascript/"

2. ¿Qué es un nodo?

Un nodo es cualquier objeto dentro del árbol del DOM. Existen varios tipos de nodos, siendo los más comunes:

  • Nodos de elemento: Representan las etiquetas HTML (divs, párrafos, encabezados, etc.)
  • Nodos de texto: Contienen el texto dentro de los elementos
  • Nodos de atributo: Representan los atributos de los elementos HTML
  • Nodos de comentario: Representan los comentarios en el HTML
  • Nodo documento: El nodo raíz que representa el documento entero

Cada nodo puede tener relaciones con otros nodos: padres, hijos y hermanos, formando así la estructura jerárquica del documento.

Referencia: https://es.javascript.info/basic-dom-node-properties

3. ¿Cómo se accede a un elemento del DOM?

Existen varios métodos para acceder a elementos del DOM:

  • document.getElementById("id"): Devuelve el elemento con el ID especificado
  • document.getElementsByClassName("clase"): Devuelve una colección HTML de elementos con la clase especificada
  • document.getElementsByTagName("etiqueta"): Devuelve una colección de elementos con la etiqueta especificada
  • document.querySelector("selector"): Devuelve el primer elemento que coincide con el selector CSS especificado
  • document.querySelectorAll("selector"): Devuelve todos los elementos que coinciden con el selector CSS especificado
Ejemplo: 
// Acceder a un elemento por ID
const elemento = document.getElementById("miElemento");

// Acceder al primer párrafo de una clase específica
const primerParrafo = document.querySelector("p.miClase");
Referencia: https://www.freecodecamp.org/espanol/news/que-es-el-dom-el-significado-del-modelo-de-objeto-de-documento-en-javascript/"

4. ¿Cómo se modifica un elemento del DOM?

Una vez que tienes acceso a un elemento del DOM, puedes modificarlo de varias maneras:

  • Modificar el contenido: elemento.textContent, elemento.innerHTML
  • Modificar atributos: elemento.setAttribute("atributo", "valor")
  • Modificar estilos: elemento.style.propiedad = "valor"
  • Añadir/eliminar clases: elemento.classList.add("clase"), elemento.classList.remove("clase")
  • Crear nuevos elementos: document.createElement("etiqueta")
  • Añadir elementos: padre.appendChild(hijo), padre.insertBefore(nuevo, referencia)
  • Eliminar elementos: padre.removeChild(hijo) o elemento.remove()
Ejemplo: 
// Modificar el texto de un elemento
document.getElementById("miElemento").textContent = "Nuevo texto";

// Cambiar el color de fondo
document.querySelector(".miClase").style.backgroundColor = "blue";

// Añadir una clase
document.getElementById("miElemento").classList.add("destacado");
Referencia: MDN Web Docs - Element

5. ¿Cuál es la diferencia entre getElementby* y querySelector*?

Las principales diferencias son:

getElementBy* querySelector*
Métodos específicos para cada tipo de selección (ID, clase, etiqueta) Método único que acepta cualquier selector CSS válido
Devuelve HTMLCollection (viva/dinámica) Devuelve NodeList (estática)
Generalmente más rápido para selecciones simples Más versátil pero puede ser menos eficiente
No permite selectores complejos Permite selectores CSS complejos (combinadores, pseudo-clases, etc.)

Por ejemplo, para seleccionar todos los párrafos dentro de un div con clase "contenido":

// Con getElementBy* requeriría múltiples pasos
const divs = document.getElementsByClassName("contenido");
for (const div of divs) {
    const parrafos = div.getElementsByTagName("p");
    // hacer algo con los párrafos
}

// Con querySelector* en un solo paso
const parrafos = document.querySelectorAll("div.contenido p");
Referencia: https://www.freecodecamp.org/espanol/news/que-es-el-dom-el-significado-del-modelo-de-objeto-de-documento-en-javascript/"

6. ¿Qué es un evento?

Un evento es una señal que indica que algo ha ocurrido en la página web. Los eventos pueden ser generados por el usuario (como clics, movimientos del ratón, pulsaciones de teclas) o por el navegador (como la carga de la página, cambios en el tamaño de la ventana). Los eventos permiten que el código JavaScript responda a estas acciones de manera dinámica.

Algunos eventos comunes incluyen:

  • click: Se dispara cuando se hace clic en un elemento
  • mouseover, mouseout: Se disparan cuando el puntero entra o sale de un elemento
  • keydown, keyup: Se disparan cuando se presiona o suelta una tecla
  • submit: Se dispara cuando se envía un formulario
  • load: Se dispara cuando el documento o un recurso ha terminado de cargar
Referencia: MDN Web Docs - Referencia de eventos

7. ¿Qué es un listener?

Un listener (o escuchador de eventos) es una función que "escucha" un evento específico y ejecuta código en respuesta cuando ese evento ocurre. Los listeners permiten crear interactividad en las páginas web, haciendo que respondan a las acciones del usuario o a otros eventos del navegador.

En JavaScript, se añaden listeners a los elementos utilizando el método addEventListener():

// Sintaxis básica
elemento.addEventListener(tipoDeEvento, funcionCallback);

// Ejemplo práctico
const boton = document.getElementById("miBoton");
boton.addEventListener("click", function() {
    alert("¡Has hecho clic en el botón!");
});

También es posible eliminar listeners con removeEventListener().

Referencia: MDN Web Docs - addEventListener

8. ¿Qué es un callback?

Un callback es una función que se pasa como argumento a otra función para ser ejecutada posteriormente. En el contexto de eventos del DOM, un callback es la función que se ejecutará cuando ocurra el evento especificado.

Los callbacks son fundamentales en JavaScript debido a su naturaleza asíncrona, permitiendo que el código responda a eventos futuros sin bloquear la ejecución del programa.

// Ejemplo de función callback en un evento
document.getElementById("miBoton").addEventListener("click", function(event) {
    // Esta función es el callback que se ejecutará cuando ocurra el clic
    console.log("El botón fue clickeado");
    console.log("Objeto de evento:", event);
});

// Otro ejemplo con una función nombrada como callback
function manejarClic(event) {
    console.log("Clic detectado");
}

document.getElementById("otroBoton").addEventListener("click", manejarClic);
Referencia: https://www.freecodecamp.org/espanol/news/que-es-una-funcion-callback-javascript/

9. ¿Qué es un objeto de evento?

Un objeto de evento es un objeto que se crea automáticamente cuando ocurre un evento y se pasa como primer argumento a la función callback. Este objeto contiene información detallada sobre el evento ocurrido, como:

  • event.target: El elemento que disparó el evento
  • event.type: El tipo de evento (click, mouseover, etc.)
  • event.clientX/Y: Las coordenadas del ratón (en eventos de ratón)
  • event.key: La tecla presionada (en eventos de teclado)
  • event.preventDefault(): Método para cancelar el comportamiento predeterminado
  • event.stopPropagation(): Método para detener la propagación del evento

Ejemplo de uso:

document.body.addEventListener("click", function(event) {
    // Muestra las coordenadas del clic
    console.log(`Clic en coordenadas: X=${event.clientX}, Y=${event.clientY}`);
    
    // Muestra el elemento que recibió el clic
    console.log("Elemento clickeado:", event.target);
    
    // Si el elemento clickeado es un enlace, previene la navegación
    if (event.target.tagName === "A") {
        event.preventDefault();
        console.log("Navegación prevenida");
    }
});
